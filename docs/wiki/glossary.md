# Glossary

## Terms

- AI security item: A public finding, advisory, incident, control change, standard, research result, or operational practice with a concrete AI security implication.
- Durable leaf: A focused page for a security concept that can change independently.
- Upstream-owned entity: A broad AI entity owned by ai-wiki or a general AI-development practice owned by ai-dev-wiki.
- Local security lens: Security-specific threat, control, assurance, governance, or incident analysis maintained here.
- Raw-only collector: An automation that saves public source evidence under raw without editing docs/wiki.
- Qualifying update: A source with visible date evidence and a concrete security fact or change inside the configured time window.
