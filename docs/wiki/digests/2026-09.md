# September 2026 AI Security Digest

## Current Understanding

- 2026-09-02: [LiteLLM MCP authentication bypass KEV](../agent-and-tool-security/litellm-mcp-authentication-bypass-kev.md) records active exploitation of CVE-2026-59822 where OAuth passthrough fallback can expose MCP tools without a valid LiteLLM key.
- 2026-09-02: [LiteLLM provider credential routing leak](../data-and-privacy/litellm-provider-credential-routing-leak.md) records CVE-2026-84377 as a model-proxy secret boundary where authenticated users can redirect provider calls and leak configured credentials.
- 2026-09-02: [Windows ML CLI localhost trust_remote_code RCE](../infrastructure-and-supply-chain/windows-ml-cli-localhost-trust-remote-code-rce.md) records browser-origin abuse of an unauthenticated local AI runtime API into remote model-code import.
- 2026-09-02: [TOON decoder prototype pollution](../model-and-prompt-security/toon-decoder-prototype-pollution.md) treats compact prompt serialization as an input-parser boundary when untrusted keys can mutate JavaScript prototypes.
- 2026-09-02: [Tencent AI-Infra-Guard skill-scan bytecode bypass](../testing-and-assurance/tencent-ai-infra-guard-skill-scan-bytecode-bypass.md) records CVE-2026-84809 as a scanner skip-list flaw for compiled Python bytecode in skill packages.
- 2026-09-02: [claude-skill-antivirus manifest-only scan](../testing-and-assurance/claude-skill-antivirus-manifest-only-scan.md) records CVE-2026-84810 as a SAFE-verdict risk when local skill directories are reduced to `SKILL.md`.
- 2026-09-02: [agentverus-scanner compiled bytecode certification bypass](../testing-and-assurance/agentverus-scanner-compiled-bytecode-certification-bypass.md) records CVE-2026-84811 as a certification blind spot for malicious companion bytecode.
- 2026-09-02: [CowAgent tool denial of service](../agent-and-tool-security/cowagent-tool-denial-of-service.md) groups BrowserTool and Bash Tool availability disclosures for remote disruption of delegated browsing or shell-tool automation.
- 2026-09-02: [aichat API endpoint memory allocation DoS](../agent-and-tool-security/aichat-api-endpoint-memory-allocation-dos.md) records a self-hosted assistant API availability boundary around uncontrolled memory allocation in `src/serve.rs`.
- 2026-09-01: OpenAI's Astra disclosure updates [frontier model critical cyber release gates](../testing-and-assurance/frontier-model-critical-cyber-release-gates.md) with a primary Critical-threshold designation, Daybreak Blue access path, stronger refusal behavior, monitoring, and limited advanced-cyber access.
- 2026-09-01: [Codex PowerShell stop-parsing approval bypass](../agent-and-tool-security/codex-powershell-stop-parsing-approval-bypass.md) shows command-approval parsers need shell-semantics parity before repository instructions can trigger file-writing commands or MCP configuration changes.
- 2026-09-01: [Codex Git metadata execution boundaries](../infrastructure-and-supply-chain/codex-git-metadata-execution-boundaries.md) groups CVE-2026-19592 and CVE-2026-19593 because preserved Git fsmonitor, attr, and filter configuration can execute before model interaction or command approval.
- 2026-09-01: [Hugging Face Transformers trust_remote_code cache write](../infrastructure-and-supply-chain/huggingface-transformers-trust-remote-code-cache-write.md) records that remote custom-generate code can be cached before trust consent, leaving persistent model-loading supply-chain residue.
- 2026-09-01: [ModelScope unsafe YAML loader RCE](../infrastructure-and-supply-chain/modelscope-unsafe-yaml-loader-rce.md) records model configuration parsing as a code-execution boundary when unsafe PyYAML object construction is allowed.
- 2026-09-01: [Elasticsearch ML model artifact deserialization RCE](../infrastructure-and-supply-chain/elasticsearch-ml-model-artifact-deserialization-rce.md) treats trained model deployment rights as code-execution-adjacent infrastructure authority.
- 2026-09-01: [Kibana AI Assistant and Agent Builder DoS](../agent-and-tool-security/kibana-ai-assistant-and-agent-builder-dos.md) records low-privilege AI feature requests that can terminate Kibana or exhaust memory across users.
- 2026-09-01: [Kibana AI Assistant Knowledge Base cross-realm authorization](../identity-and-access/kibana-ai-assistant-knowledge-base-cross-realm-authorization.md) records assistant-memory access crossing realms when same usernames are not bound to stable principals.
- 2026-09-01: [runZero Platform MCP authorization bypass](../agent-and-tool-security/runzero-platform-mcp-authorization-bypass.md) records a fixed Platform MCP service user-controlled-key authorization issue in version 5.1.260826.0.
- 2026-09-01: [hermes-agent ACP MCP DoS](../agent-and-tool-security/hermes-agent-acp-mcp-dos.md) groups ACP prompt workflow and MCP tool memory-allocation denial-of-service records for hermes-agent through 0.18.2.
- 2026-09-01: [Support Genix AI Chatbot admin takeover](../identity-and-access/support-genix-ai-chatbot-admin-takeover.md) records weak guest-ticket token cryptography that can turn AI helpdesk access into WordPress administrator access.
