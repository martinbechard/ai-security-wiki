# July 2026 AI Security Digest

## Current Understanding

- 2026-07-24: [OpenAI Hugging Face cyber-evaluation incident](../incident-response/openai-hugging-face-cyber-evaluation-incident.md) consolidates July 22 and July 24 evidence for evaluation containment, egress, credential, package-proxy, and defender-access controls.
- 2026-07-24: [AI-assisted exploit development acceleration](../threats-and-attacks/ai-assisted-exploit-development-acceleration.md) records Kimi K3-assisted Redis RCE reporting as patch-pressure evidence while preserving uncertainty about autonomy.
- 2026-07-23: [cross-site agent forgery](../agent-and-tool-security/cross-site-agent-forgery.md) treats AgentForger as a persistent delegated-authority risk across agent creation, connector inheritance, approvals, scheduling, and preview execution.
- 2026-07-23: [n8n AI Agent Project Viewer privilege escalation](../agent-and-tool-security/n8n-ai-agent-project-viewer-privilege-escalation.md) shows why AI agent tools must authorize the final action against the requesting user's effective role.
- 2026-07-23: [AI-hosted artifact malware delivery](../threats-and-attacks/ai-hosted-artifact-malware-delivery.md) records FakeAgent abuse of Claude Artifacts as a trusted-domain malware delivery and artifact-provenance issue.
- 2026-07-23: [public cyber-capability assessments](../testing-and-assurance/public-cyber-capability-assessments.md) captures NIST CAISI and UK AISI Kimi K3 cyber-assessment results as release-gate and monitoring evidence.
- 2026-07-23: [unattended AI agent attack automation](../threats-and-attacks/unattended-ai-agent-attack-automation.md) records Hermes AI agent use in intrusion reporting as incident evidence for approval mode, scope, and runtime logs.
- 2026-07-23: [Langflow KEV remote code execution](../agent-and-tool-security/langflow-kev-rce.md) records active exploitation of CVE-2026-0770 in an AI workflow platform and treats exposed agent orchestration infrastructure as a KEV-gated operations surface.
- 2026-07-23: [MaxKB MCP tool import remote code execution](../agent-and-tool-security/maxkb-mcp-tool-import-rce.md) shows how imported MCP `stdio` transport configuration can cross from tool metadata into command execution.
- 2026-07-23: [AI data center security standards](../governance-and-compliance/ai-data-center-security-standards.md) tracks NIST standards work that explicitly includes training, inference, agentic workflows, access control, supply chain, OT, facilities, and compliance boundaries.
- 2026-07-23: [ATO-approved sensitive data use](../data-and-privacy/ato-approved-sensitive-data-use.md) maps VA generative AI guidance into a reusable control: sensitive data belongs only in tools whose approval boundary covers that data class.
- 2026-07-23: [AI coding telemetry redaction controls](../data-and-privacy/ai-coding-telemetry-redaction-controls.md) records source-side and ingestion-time redaction as privacy controls for prompts, code, secrets, tool I/O, and system instructions.
- 2026-07-22: [mcp-webresearch browser SSRF](../agent-and-tool-security/mcp-webresearch-browser-ssrf.md) shows how prompt injection can steer a server-side browser tool into internal or metadata endpoints; no fixed npm version was visible during ingest.
- 2026-07-22: [Network-AI ApprovalInbox authorization bypass](../agent-and-tool-security/network-ai-approval-inbox-authorization-bypass.md) exposes queued agent action metadata through read and stream routes; the [GitHub advisory](https://github.com/Jovancoding/Network-AI/security/advisories/GHSA-m4jg-6w3q-gm86) lists 5.13.4 as patched.
- 2026-07-22: [Google MCP Toolbox BigQuery forecast boundary bypass](../agent-and-tool-security/google-mcp-toolbox-bigquery-forecast-boundary-bypass.md) shows why MCP data tools must validate final assembled queries, not only selected dataset parameters.
- 2026-07-22: [next-ai-draw-io provider disclosure](../data-and-privacy/next-ai-draw-io-provider-disclosure.md) tracks provider-spoofed prompt and conversation disclosure through client-selected AI provider overrides.
- 2026-07-22: [next-ai-draw-io MCP server path traversal](../agent-and-tool-security/next-ai-draw-io-mcp-server-path-traversal.md) records filesystem-write risk in an MCP export tool and unresolved fixed-version evidence.
- 2026-07-22: [Network-AI environment restore path traversal](../infrastructure-and-supply-chain/network-ai-environment-restore-path-traversal.md) records a pre-5.12.2 backup restore boundary bypass fixed by backup ID validation and resolved-path checks.
